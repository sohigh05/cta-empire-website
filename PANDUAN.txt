CTA EMPIRE — PANDUAN FAIL WEBSITE
================================

1. MEMBUKA WEBSITE

   Buka dist/index.html dalam pelayar. Semua halaman menggunakan HTML,
   CSS dan JavaScript biasa. Sambungan internet diperlukan untuk fon
   Google, peta, Google Maps, Waze dan WhatsApp.

   Untuk pratonton melalui pelayan tempatan, jalankan dari folder ini:
   python -m http.server 4173 --directory dist

   Kemudian buka http://localhost:4173


2. SUSUNAN FAIL

   dist/index.html           Halaman utama
   dist/tentang.html         Profil, pemilik, organisasi dan sijil
   dist/it.html              Tiga perkhidmatan laman web
   dist/construction.html    Empat perkhidmatan penyelenggaraan
   dist/projek.html          Projek Pakej IP B21
   dist/hubungi.html         Hubungan, borang pertanyaan dan peta

   dist/css/style.css        Tema, navigasi, halaman utama dan animasi
   dist/css/halaman.css      Gaya halaman dalaman dan borang
   dist/js/script.js         Menu, transisi logo, skrol dan tab
   dist/js/interaksi.js      Cadangan servis, WhatsApp dan galeri sijil
   dist/assets/images/       Logo asal dan visual daripada profil
   dist/assets/sijil/         Enam pratonton sijil berwatermark

   Komen dalam Bahasa Melayu menerangkan fungsi setiap bahagian.
   Tiada framework atau langkah kompilasi diperlukan.

5. SIJIL DAN HAK CIPTA

   Sijil mempunyai watermark CTA EMPIRE pada sudut 45 darjah yang
   dilekatkan terus pada imej. Nombor pengenalan, nombor cukai peribadi,
   QR yang berpotensi mendedahkan maklumat dan ID pengguna disamarkan.

   PDF asal, penyata bank dan surat perjanjian tidak termasuk dalam
   folder website atau pakej penghantaran.

   Klik kanan, seretan imej dan tindakan simpan biasa dihadkan pada
   pemapar sijil. Website tidak boleh menjamin sekatan screenshot
   peranti atau menghalang pengguna teknikal memperoleh imej pratonton.
   Watermark dan penyamaran data kekal pada imej yang dipaparkan.
