CTA EMPIRE — PANDUAN FAIL WEBSITE
================================

1. MEMBUKA WEBSITE

   Semua halaman menggunakan HTML, CSS dan JavaScript biasa.
   Gunakan pelayan tempatan atau hosting untuk mengaktifkan pop-up
   IT dan Construction. Jika index.html dibuka terus sebagai fail,
   pautan bidang membuka halaman penuh sebagai paparan sandaran.
   Sambungan internet diperlukan untuk fon Google, peta dan WhatsApp.

   Untuk pratonton melalui pelayan tempatan, jalankan dari folder ini:
   python -m http.server 4173 --directory dist

   Kemudian buka http://localhost:4173


2. SUSUNAN FAIL

   dist/index.html           Halaman utama
   dist/tentang.html         Profil, pemilik, organisasi dan sijil
   dist/it.html              Tiga perkhidmatan laman web
   dist/construction.html    Empat perkhidmatan penyelenggaraan
   dist/projek.html          Projek Pakej IP B21
   dist/hubungi.html         Hubungan, borang pertanyaan dan peta

   dist/css/style.css        Tema, navigasi, halaman utama dan animasi
   dist/css/halaman.css      Gaya halaman dalaman dan borang
   dist/js/script.js         Menu, loading, transisi logo dan skrol
   dist/js/interaksi.js      Cadangan servis, WhatsApp dan galeri sijil
   dist/js/aliran.js         Dua aliran dengan pop-up maklumat penuh
   dist/assets/images/       Logo asal dan foto sebenar pasukan
   dist/assets/sijil/         Enam pratonton sijil berwatermark

   Komen dalam Bahasa Melayu menerangkan fungsi setiap bahagian.
   Tiada framework atau langkah kompilasi diperlukan.

7. PENYELENGGARAAN

   Warna biru, kuning keemasan dan latar cerah ditetapkan dalam :root
   pada css/style.css. Maklumat pop-up dibaca daripada it.html dan
   construction.html supaya kandungan hanya perlu disunting sekali.

   Loading pembukaan dipaparkan selama 1.8 saat pada setiap pembukaan
   biasa. Logo transisi dipaparkan selama 1.1 saat sebelum halaman atau
   pop-up dibuka. Pilihan sistem untuk kurang gerakan turut dihormati.

   Semak semula sijil yang mempunyai tarikh luput sebelum memperbaharui
   kandungan. Kemas kini butiran hubungan pada semua halaman berkaitan.
   Kekalkan folder assets, css dan js bersama fail HTML ketika memindahkan
   website ke penyedia hosting lain.
